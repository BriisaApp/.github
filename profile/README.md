### What it is

Briisa is a ticketing platform for festivals, concerts and conferences, with an app that stays useful on site, where the mobile network usually collapses.

- **Ticket, site map, programme and emergency screen** in one app.
- **Opt-in proximity social layer:** a radar of people nearby, double opt-in matching and end-to-end encrypted chat, over a fully offline Bluetooth and Wi-Fi mesh.
- **Offline gate app for staff** to scan tickets without a connection.
- **Back-office and web** for organisers.

### Under the hood

| | |
|---|---|
| **Core** | Kotlin module (crypto, identity, mesh, safety) embedded as a Flutter plugin, with cross-language test vectors |
| **Mobile** | Flutter: attendee app and staff gate app |
| **Backend** | NestJS, Prisma, PostgreSQL, Socket.IO |
| **Web & back-office** | Next.js |
